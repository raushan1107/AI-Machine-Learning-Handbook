Build It Yourself — Hands-On Lab Guide

This page is different from the theory handbook and the reference notebook. It's a step-by-step build guide: open a blank Jupyter notebook of your own, copy each step's code into a new cell in order, run it, compare your output to what's shown, and move to the next step at your own pace. Every code block below is copied exactly from the tested reference notebook — nothing here is untested or approximate.

How this page is different from the reference notebook
The reference-notebooks/ files are the finished, instructor-built version — useful to compare against or fall back on. This page instead walks you through building your own copy from a blank notebook, one small, explained step at a time, so the typing and the pauses to think are part of the learning.

Before you start — setup & assumptions

These steps are OS-agnostic and assume no prior setup. If you already have Python and Jupyter working, skip to "Create your project folder."

1 · Install Python (3.10 or newer)

  1. Download from python.org/downloads (Windows/macOS) or use your package manager on Linux.
  2. Windows: during install, tick "Add python.exe to PATH."
  3. Verify it worked — open a terminal (Command Prompt / Terminal) and run:
python --version

You should see something like Python 3.11.x. If you see "command not found," try python3 --version instead.

2 · Create your project folder

Every module in this course reads and writes to the SAME two folders, so create this structure once:

mkdir rr-finance-ai
cd rr-finance-ai
mkdir data
mkdir artifacts

Do all your work for every module inside this one rr-finance-ai folder — Module 2's lab literally cannot run without files Module 1's lab saves into data/ and artifacts/.

3 · Create a virtual environment (recommended)

Keeps this course's packages separate from anything else on your machine.

python -m venv .venv
Activate it — click for your OS

Windows (Command Prompt):

.venv\Scripts\activate

macOS / Linux:

source .venv/bin/activate

You'll know it worked when your terminal prompt shows (.venv) at the start of the line. Do this every time you reopen a terminal for this project.

4 · Install Jupyter

pip install notebook jupyterlab

Prefer Anaconda instead? It already includes Jupyter — install from anaconda.com/download and skip this step.

5 · Launch Jupyter and create your notebook

jupyter notebook

This opens a browser tab at localhost:8888, showing your rr-finance-ai folder. Click New → Notebook, choose the Python 3 kernel, and rename it (top-left) to:

  • Module 1 → module1_lab.ipynb
  • Module 2 → module2_lab.ipynb

Prefer JupyterLab or VS Code's notebook editor instead? Either works identically — jupyter lab launches JupyterLab.

6 · Get the dataset

Download rr_finance_module1_dataset.csv and place it inside your data/ folder, so the path from your notebook is exactly data/rr_finance_module1_dataset.csv.

⬇ Download the dataset

Module 1's lab creates everything else (the enriched dataset, the trained model, the anomaly detector) — you only need to manually place this one file.

Skip steps 1–5 entirely — Colab already has Python and Jupyter-style notebooks in your browser at colab.research.google.com. You still need the folder structure: run !mkdir -p data artifacts in your first cell, then upload the CSV with:

Rules for working through this page
  • Go in order. Later steps use variables created in earlier steps — skipping ahead will cause a NameError.
  • One step = one new cell. Don't merge multiple steps into one cell; keeping them separate makes it easier to see exactly which step produced which output.
  • Read "Expected output" before panicking. Your exact numbers may differ slightly (randomness, package versions) — the shape and scale of the output is what matters.
  • If a cell errors with ModuleNotFoundError, scroll up and re-run the Setup install cell first.
  • If a cell errors with FileNotFoundError for the CSV, double-check the file is at data/rr_finance_module1_dataset.csv relative to where you launched Jupyter.
  • If anything gets into a confusing state, use the notebook menu: Kernel → Restart & Clear Output, then run your cells again from the top.

# IQR-based outlier scan on the key numeric fields
outlier_summary = {}
for col in ["annual_income", "monthly_debt", "loan_amount", "credit_score", "age"]:
    q1, q3 = df[col].quantile([0.25, 0.75])
    iqr = q3 - q1
    lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
    n_outliers = ((df[col] < lower) | (df[col] > upper)).sum()
    outlier_summary[col] = n_outliers
    print(f"{col:16s} range [{df[col].min():>10.0f}, {df[col].max():>10.0f}]  IQR outliers: {n_outliers}")

        self.w = np.zeros(n_inputs)
        self.b = 0.0
        self.lr = lr

    def predict(self, x):
        z = np.dot(x, self.w) + self.b
        return 1 if z >= 0 else 0

    def fit(self, X, y, epochs=20):
        for _ in range(epochs):
            for xi, yi in zip(X, y):
                pred = self.predict(xi)
                error = yi - pred
                self.w += self.lr * error * xi
                self.b += self.lr * error

def sigmoid_np(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_deriv(a):
    # derivative of sigmoid, expressed in terms of its OWN output "a" -- a common and efficient trick
    return a * (1 - a)

# Tiny toy dataset: 2 samples, 2 features each
X_toy = np.array([[0.5, -0.2], [0.1, 0.9]])
y_toy = np.array([[1.0], [0.0]])

rng = np.random.default_rng(SEED)
W1 = rng.normal(0, 0.1, size=(2, 3)); b1 = np.zeros((1, 3))
W2 = rng.normal(0, 0.1, size=(3, 1)); b2 = np.zeros((1, 1))

def forward(X, W1, b1, W2, b2):
    z1 = X @ W1 + b1
    a1 = sigmoid_np(z1)
    z2 = a1 @ W2 + b2
    a2 = sigmoid_np(z2)
    return z1, a1, z2, a2

def mse_loss(a2, y):
    return np.mean((a2 - y) ** 2)

z1, a1, z2, a2 = forward(X_toy, W1, b1, W2, b2)
loss = mse_loss(a2, y_toy)
print("Forward pass loss:", loss)

# --- Backward pass (manual chain rule) ---
m = X_toy.shape[0]
dA2 = (a2 - y_toy) * (2 / m)
dZ2 = dA2 * sigmoid_deriv(a2)
dW2 = a1.T @ dZ2
db2 = dZ2.sum(axis=0, keepdims=True)

dA1 = dZ2 @ W2.T
dZ1 = dA1 * sigmoid_deriv(a1)
dW1 = X_toy.T @ dZ1
db1 = dZ1.sum(axis=0, keepdims=True)

print("Analytical dW1[0,0]:", dW1[0, 0])

# --- Numerical gradient check on W1[0,0] ---
eps = 1e-5
W1_plus = W1.copy();  W1_plus[0, 0] += eps
W1_minus = W1.copy(); W1_minus[0, 0] -= eps

_, _, _, a2_plus  = forward(X_toy, W1_plus,  b1, W2, b2)
_, _, _, a2_minus = forward(X_toy, W1_minus, b1, W2, b2)

numerical_grad = (mse_loss(a2_plus, y_toy) - mse_loss(a2_minus, y_toy)) / (2 * eps)

def conv2d_manual(image, kernel, stride=1, padding=0):
    """A from-scratch 2D convolution -- purely to make the sliding-window mechanic visible."""
    if padding > 0:
        image = np.pad(image, ((padding, padding), (padding, padding)))
    ih, iw = image.shape
    kh, kw = kernel.shape
    oh = (ih - kh) // stride + 1
    ow = (iw - kw) // stride + 1
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            region = image[i*stride : i*stride+kh, j*stride : j*stride+kw]
            out[i, j] = np.sum(region * kernel)
    return out

    """A small CNN for 28x28 grayscale digit images -- the RR Finance cheque-digit reader prototype."""
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 16, kernel_size=3, padding=1)
        self.bn1   = nn.BatchNorm2d(16)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        self.bn2   = nn.BatchNorm2d(32)
        self.pool  = nn.MaxPool2d(2, 2)
        self.dropout = nn.Dropout(0.25)
        self.fc1   = nn.Linear(32 * 7 * 7, 128)   # 28 -> pool -> 14 -> pool -> 7
        self.fc2   = nn.Linear(128, 10)

    def forward(self, x):
        x = self.pool(F.relu(self.bn1(self.conv1(x))))   # 28x28 -> 14x14, 16 channels
        x = self.pool(F.relu(self.bn2(self.conv2(x))))    # 14x14 -> 7x7,   32 channels
        x = x.view(x.size(0), -1)                          # flatten for the fully-connected head
        x = self.dropout(F.relu(self.fc1(x)))
        return self.fc2(x)   # raw logits -- CrossEntropyLoss applies softmax internally

Lesson 10 (Lab) — Cybersecurity: adversarial examples (FGSM and PGD)

Attack your own trained CNN with FGSM and PGD — tiny, calculated pixel perturbations that fool a correctly-trained model at prediction time.

Step 1Create a new cell, paste the code below, then press Shift+Enter to run it.
def fgsm_attack(model, images, labels, epsilon):
    """One-step adversarial attack: move each pixel by +/- epsilon in the direction that increases the loss."""
    images = images.clone().detach().requires_grad_(True)
    logits = model(images)
    loss = criterion(logits, labels)
    model.zero_grad()
    loss.backward()

    perturbation = epsilon * images.grad.sign()
    adv_images = (images + perturbation).clamp(-3, 3).detach()   # clamp to a sane normalized-pixel range
    return adv_images


def pgd_attack(model, images, labels, epsilon, alpha, steps):
    """Iterative adversarial attack: several small FGSM-style steps, projected back within the epsilon budget."""
    original = images.clone().detach()
    adv_images = images.clone().detach()

    for _ in range(steps):
        adv_images.requires_grad_(True)
        logits = model(adv_images)
        loss = criterion(logits, labels)
        model.zero_grad()
        loss.backward()

        with torch.no_grad():
            adv_images = adv_images + alpha * adv_images.grad.sign()
            perturbation = torch.clamp(adv_images - original, -epsilon, epsilon)   # <- the "projection" in PGD
            adv_images = (original + perturbation).clamp(-3, 3)
        adv_images = adv_images.detach()

    return adv_images
