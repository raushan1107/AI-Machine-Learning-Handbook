How to use this handbook

1. Read the theory

Each module page explains what an algorithm is, why it exists, its history, its alternatives, and where it shows up in real financial systems — before you touch code.

2. Build it yourself

Use the hands-on lab guide to type each step into your own blank notebook, one explained piece at a time — the copy-paste-run flow that actually builds muscle memory.

3. Compare against the reference

Download the matching .ipynb to check your work or move faster, then move to the next module — every module saves its artifacts for the next one to load.
